⭐ Recommended — Apps Script Web App (most reliable)
  1. Open your Google Sheet → Extensions → Apps Script.
  2. Paste the contents of apps-script.gs (in project folder), save (Ctrl+S).
  3. Deploy → New deployment → ⚙ Web app → Who has access: Anyone → Deploy.
  4. Authorize the script (Advanced → Go to project → Allow).
  5. Copy the Web app URL (ends in /exec) → paste above → Save & Sync.
Alt — quick CSV (less reliable): Share sheet as "Anyone with the link" → paste the /edit URL above. May fail on file:// due to CORS.
Auto-refresh: every 1 minute. Use ⟳ Sync for instant refresh.
